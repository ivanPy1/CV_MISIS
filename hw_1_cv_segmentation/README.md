# Семантическая сегментация на CamVid с предобученным UNet

## 📋 Описание проекта

**Задача:** Обучение предобученной модели UNet для семантической сегментации на датасете CamVid (12 классов). Используется архитектура UNet с энкодером EfficientNet-B3, обученная с PyTorch Lightning и расширенными аугментациями.

## 🏗️ Выполненные работы

### 1. Подготовка окружения и данных
- **Установка зависимостей:** PyTorch, segmentation-models-pytorch, albumentations, pytorch-lightning
- **Загрузка датасета:** Распаковка и загрузка CamVid
- **Создание класса `CamVidDataset`** для работы с изображениями и масками
- **Реализация улучшенных аугментаций** с использованием Albumentations:
  - Ресайз, горизонтальные/вертикальные флипы
  - Аффинные преобразования (сдвиг, масштаб, поворот)
  - Цветовые преобразования (яркость, контраст, насыщенность)
  - Добавление шума и размытия
  - CoarseDropout (регуляризация)
  - Нормализация и преобразование в тензоры

### 2. Архитектура модели
- **Основная модель:** UNet с предобученным энкодером EfficientNet-B3
- **Энкодер:** timm-efficientnet-b3 с весами ImageNet
- **Количество классов:** 12 (CamVid)
- **Параметры:** ~13.2 млн
- **Особенности:**
  - Активация в декодере: None (логиты)
  - Тип внимания в декодере: scSE (spatial and channel squeeze-excitation)
  - Глубина энкодера: 5 уровней
  - Каналы декодера: [256, 128, 64, 32, 16]

### 3. Функции потерь
**Комбинированная loss функция для улучшения обучения:**
- **Focal Loss** (α=0.8, γ=2.0) — для решения проблемы дисбаланса классов
- **Dice Loss** (multiclass) — для улучшения метрики IoU
- **Cross-Entropy Loss** — стандартная классификационная loss
- **Финальная loss:** 0.4×Focal + 0.4×Dice + 0.2×CE

### 4. Обучение с PyTorch Lightning
**Реализация Lightning Module:**
- Поддержка автоматического смешанной точности (AMP)
- Мониторинг метрик: train/val/test loss и IoU
- Вычисление mean IoU для всех 12 классов
- Оптимизатор AdamW с weight decay
- OneCycleLR scheduler для адаптивного изменения learning rate

**Процедура обучения:**
- Размер батча: 16
- Размер изображений: 512×512
- Learning rate: 3e-4
- Количество воркеров: 8
- Использование ModelCheckpoint, EarlyStopping, LearningRateMonitor
- Логирование в TensorBoard

### 5. Аугментации
**Для обучения:**
- Ресайз до 512×512
- Случайные горизонтальные (p=0.5) и вертикальные (p=0.1) флипы
- Аффинные преобразования (сдвиг, масштаб, поворот)
- Цветовые преобразования
- Добавление шума и размытия
- CoarseDropout для регуляризации
- Нормализация по ImageNet статистике

**Для валидации:**
- Только ресайз и нормализация

## 🛠️ Технологический стек
- **PyTorch & PyTorch Lightning** — обучение моделей
- **segmentation-models-pytorch** — предобученные модели сегментации
- **Albumentations** — аугментации изображений
- **OpenCV** — обработка изображений
- **timm** — эффективные предобученные энкодеры
- **TensorBoard** — визуализация обучения

## 📊 Метрики качества
- **Основная метрика:** Intersection over Union (IoU)
  - Вычисляется для каждого из 12 классов
  - Усредняется для получения mean IoU
- **Дополнительные метрики:**
  - Train/Val/Test Loss (комбинированная)
  - Визуализация предсказаний

## ✨ Ключевые особенности реализации
- **Предобученный энкодер** — использование EfficientNet-B3 для лучшего выделения признаков
- **Комбинированная loss** — оптимальное сочетание Focal, Dice и CE Loss
- **Расширенные аугментации** — улучшение обобщающей способности модели
- **Автоматическое обучение** — использование PyTorch Lightning для воспроизводимости
- **OneCycleLR** — адаптивный scheduler для быстрой сходимости
- **Поддержка AMP** — обучение с автоматической смешанной точностью
- **Обработка масок** — преобразование в тип Long для корректной работы с loss функциями
