# Conditional GAN на MNIST

## Реализовано:

- `ConditionalGenerator`
- `ConditionalDiscriminator`  
- `ConditionalGAN.training_step`
- Обучена модель на датасете MNIST, достингнута генерация реалистичных цифр, соответствующих заданным меткам с визуализацией меток (0-9)
- Генерируемые изображения выглядят как цифры
- Генерируемые цифры соответствуют заданным меткам 
- Визуализация показывает правильное соответствие между метками и изображениями
