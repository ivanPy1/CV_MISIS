# CV  - Homeworks

Репозиторий с домашними заданиями по курсу "Компьтерное зрение / Глубокое обучение в компьютерном зрении" (CV+VLM). 

## Список домашних заданий
# Homework 1: Сегментация с предобученным UNet

Обучение предобученной модели UNet для семантической сегментации на датасете CamVid (12 классов). Используется архитектура UNet с энкодером EfficientNet-B3, обученная с PyTorch Lightning и расширенными аугментациями.

# Homework 2: 3D Hand Keypoints Regression
